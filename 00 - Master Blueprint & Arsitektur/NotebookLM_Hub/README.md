## 1. Mengapa Menggunakan Hub Ini?
Untuk menjaga penulisan kajian 114 Surah (6.236 Ayat) tetap ringan, berkualitas tinggi, dan bebas halusinasi:
- **NotebookLM** bertindak sebagai **"Otak Riset & Verifikasi"** (*Grounding RAG Engine*).
- **Antigravity Worker Pipeline** bertindak sebagai **"Pabrik Produksi & Layout"** (*Execution Engine*).

## 3. Langkah Cepat Memulai (Hanya 3 Menit)

1. Buka **[https://notebooklm.google.com/](https://notebooklm.google.com/)** di Google Chrome.
2. Buat notebook baru, beri judul misal: `HBQ - Surah Al-Baqarah`.
3. Tarik (drag & drop) berkas berikut dari folder lokal Anda:
   - `01_Tafsir_Komparatif/002_Tafsir_Kemenag_Surah_Al-Baqarah.md`
   - `03_Asbabun_Nuzul_Takhrij/002_Asbabun_Nuzul_Al-Baqarah.md`
   - `02_Leksikografi_Morfologi/000_Mu'jam_Maqayis_Lughah_Kaidah_Akar_Kata.md`
4. Buka berkas `04_Prompt_Templates_NotebookLM/PANDUAN_DAN_PROMPT_MASTER_NOTEBOOKLM_7LENSA.md`, salin salah satu prompt (Prompt A, B, atau C), lalu tempel ke chat NotebookLM.
5. Anda akan mendapatkan ekstraksi data eksegesis atau mental model dengan sitasi akurat tanpa risiko fabrikasi data!
